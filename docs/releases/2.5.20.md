# QuackSlicer 2.5.20

## Home Assistant material source

The optional HA provider brings mounted rolls and an Inventory submenu into
the native filament dropdown. Each selection retains the physical roll UUID
independently of local filament-profile and color overrides. Synchronization
can import all occupied HA slots, append materials safely, or publish only
checked project-to-HA differences.

Published filament profiles now include complete effective settings and a
content digest. An explicit selection retrieves the matching revision and
installs a separate compatible user profile without overwriting unrelated local
presets. Background refreshes read summaries only. No print/process profile is
inferred from a printer's substitute material name.

HA is the writable stock and job authority. Row and field conflict checks allow
unrelated changes to merge, while permanent request receipts reconcile uncertain
writes without duplicate booking. Paged snapshots preserve larger histories and
replace the local cache only after a complete consistent read. Fresh roll,
stock, printer and live-slot checks remain ahead of native print dispatch.

The bundled HA component adds configurable subsets of the verified P2S slots,
complete-profile transport, ledger/profile/request recovery bundles and explicit
failed-print consumption review. Estimates remain labeled as estimates.

## Connection and camera behavior

HA credentials can be retained in the operating system credential store or for
the current session. The connection remains scoped to its configured server;
credentials are not embedded in project files or inventory journals.

Camera autostart after a print waits until the Device tab and camera are ready,
then consumes the request once. Switching printers discards the old request.
Existing user camera preferences and supported printer transport remain in effect.

## Compatibility and upgrade

This release includes the upstream safety corrections documented for
[2.5.19](2.5.19.md). Existing project roll bindings and the inventory schema are
preserved. Back up user profiles, open projects, HA inventory and pending request
journals before upgrading either side of the integration.

The current HA printer adapter supports a paired P2S with A1-A4, one HT1 and
EXT; additional printer models and AMS address maps require separate validation.
The existing `quack_material_demo` domain is retained for compatibility.
Install the matching bundled component before enabling the new provider API.

See [setup and operational limits](../HOME_ASSISTANT_MATERIALS.md) and
[component installation and recovery](../../tools/ha-material-demo/README.md).

## Verification

Regressions cover UUID persistence, profile digests and native preset reload,
large paged ledgers, reservation identity, conflict handling, receipt replay,
recovery integrity, NFC navigation and camera request ordering. The bundled
Python/JavaScript tests have their own CI workflow in addition to the native
cross-platform build and unit-test pipeline.

Release publication requires successful CI for the final merged commit and
verification of the corresponding platform assets. Physical iPhone NFC writing,
cold-start and two-phone checks remain separate acceptance work; software tests
do not establish physical printer or NFC compatibility.
