# QuackSlicer 2.5.18

## Organic support interfaces

- Generate the missing bottom contact layer when organic supports rest on a
  model. Small interface counts now produce the expected contact extrusion,
  including projects using PLA interfaces with PETG models and support bases.
- Place bottom interfaces above the model surface. Downward branch extensions
  use collision geometry at their destination layer, and bottom contacts retain
  the clipped footprint from that layer instead of restoring geometry from above.
- Check the full extrusion height against model collisions when independent
  support layer heights are enabled, including contact on sloped surfaces.
- Honor the configured bottom Z distance independently of a zero top Z distance.

Existing interface material allocation is preserved: with two configured layers
and different support/interface filaments, one layer is the interface-material
contact and the other is the support-base transition layer.

## Build compatibility

Windows ARM64 CI uses native CMake 4.3.4 to support the hosted runner's
Visual Studio 2026 toolchain. Existing legacy-policy and Boost.Context
Windows Fiber compatibility settings are retained.

## Upgrading

Existing projects and profiles remain compatible; no migration is required.
Re-slice saved projects to apply the corrected support geometry. Projects using
an inflated bottom-interface count as a workaround can return to their intended
count. Check the configured bottom Z distance: it is now respected even when
the top Z distance is zero.

## Validation

- All 11 support test cases passed (660 assertions), covering disabled, inherited,
  and explicit interface counts; zero/nonzero bottom gaps; same/different
  interface filaments; flat/sloped model surfaces; and synchronized/independent
  support heights. Collision regressions also require a bottom contact to exist.
- Local Windows CTest: 529 passed, zero failed, five NumPy-dependent binding
  tests skipped because NumPy is absent in that test interpreter.
- Re-sliced the reported PETG/PLA project and its updated two-object plate.
  Lower PLA contacts print at Z 2.4 mm above the Z 2.0 mm model surface, with
  the configured 0.2 mm gap. No sampled lower-contact extrusion points intersect
  the model. The user confirmed that the reported problem is resolved.
- Publication requires the complete configured cross-platform build and test
  workflow. Digital geometry checks do not establish physical adhesion,
  removability, or final print quality.
