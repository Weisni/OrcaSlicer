# QuackSlicer 2.5.21

## Recover from rejected print preparation

When Home Assistant rejects a print request, for example because another
request still requires completion or review, QuackSlicer now routes that error
to the existing job finalizer and print-dialog error message. Previously the
main-thread callback could throw into the UI event loop and terminate the app.
The original exception is preserved for cleanup and reporting, and subsequent
jobs can run after a rejected request.

Print, send, arrange, orient and fill-bed preparation callbacks retrieve their
future result so a failed preparation stops the job before it proceeds.
Successful preparation follows the existing path.

## Compatibility

Existing project formats, printer profiles and inventory schemas retain their
current behavior. This repair uses the existing HA reservation reconciliation
and native printer transport. Managed `HA ... [digest]` filament presets are
intended local effective copies of HA material settings.

## Verification

Two worker regressions reproduced the original callback failure before the
correction and pass all 18 assertions afterward, including a subsequent
successful job and preservation of nonstandard exceptions. The local GUI
utility CTest run passed 105 cases with five optional NumPy cases skipped;
existing `NotWorking` HTTP cases were excluded. The unchanged core test binaries
also passed 46 HA material/selection cases (219 assertions) and 57
inventory/lifecycle cases (1,023 assertions).

An incremental Windows Release repair reached a responsive main window with
an isolated empty data directory. Source inspection confirms the actual print
dialog wraps `PrintJob` in `PlaterWorker`, which reports and consumes standard
exceptions after the inner finalizer performs reservation cleanup.

Release publication requires successful cross-platform CI on the final merged
commit and verification of its matching platform assets. An actual accepted
HA dispatch, physical printer behavior and the separately reported nozzle-match
indicator remain separate acceptance work.
