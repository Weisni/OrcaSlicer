# QuackSlicer 2.5.26

## Changes

- Preserve project filament slots and Home Assistant roll bindings when
  changing nozzle diameter on the same single-extruder printer. A saved nozzle
  variant can still supply its process preset.
- Recalculate flushing volumes when Home Assistant applies changes to project
  materials. Orca's **All**, **Color**, and **None** preferences control when
  the calculation runs. Manually tuned volumes between unaffected slots and
  the flush multiplier are preserved.
- Print the configured number of support interface layers with the selected
  non-soluble interface filament, including for organic supports. Soluble
  zero-gap interfaces retain their dense base-material treatment.
- Use Orca's shared entry point for standard top and bottom color
  penetration and its typed speed lookup for automatic brim. Existing
  Projected and surface-normal settings and legacy brim overrides are supported.

This regular patch release retains the OrcaSlicer 2.5.0 Beta source basis
of QuackSlicer 2.5.25.

## Validation

- The user confirmed the HA material sync in the isolated test build. In a
  Windows GUI trial with two loopback HA rolls, the stale 293/679 mm³ matrix
  updated automatically to 635/183 mm³ for black and white.
- The normal and organic support trials use the interface filament at all
  three configured heights. The saved Generic-profile project slices and
  exports. The tested paint and brim paths match the previous test build.
- The regular candidate requires the hosted Windows x64 build, native tests,
  and HA regression gate at its exact source revision. The release workflow
  uses the installer and portable ZIP from that build. Additional platforms
  are available through the opt-in build matrix.
