# QuackSlicer 2.5.17

## Order management

- Archive completed or cancelled orders and restore them when needed. Archiving
  preserves print jobs, costs, invoice details, and customer totals. Orders with
  unresolved print jobs must be resolved before archiving.
- Work in separate **Orders** and **Customers** tabs under **Filaments**.
- Find orders using adjacent search, status, and archive filters. Search includes
  order numbers, titles, notes, and customer names.
- See status first, with readable badges. Orders are sorted by **Active, Draft,
  Completed, Cancelled**, then alphabetically by the displayed order name.
- Focus on eight primary columns; enable **Cost details** for the full breakdown.
- Use compact, themed actions and scrollable customer, order, cost, and invoice
  dialogs. Selection is retained after refresh, and newly created orders remain
  visible even when earlier filters would exclude them.

## Build reliability

Project-owned headers are separated from third-party system includes. The local
Windows startup failure was resolved with a consistent rebuild after identifying
incompatible stale objects. The previously released cross-platform 3MF import
build fix is retained.

## Upgrading

The inventory database automatically migrates from schema 7 to schema 8, adding
an archive flag to existing orders without changing their status or history.
Back up the inventory database before upgrading if you may need to return to
2.5.16: older versions cannot open a schema-8 inventory. Restore archived orders
before editing them or their linked historical jobs.

Project files and printer profiles remain compatible. The existing built-in
arrangement tool is unchanged; the experimental additional arranger is not part
of this release.
